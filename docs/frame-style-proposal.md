> 历史设计记录。2026-10-26 已精简为样式、背景、三档留白和简单水印；当前行为以 [图片美化](image-beautify.md) 为准。

以下保留原提案；实际参数与边界以 [图片美化](image-beautify.md) 为准。纸框本轮保持水平，未加入旋转。

## 1. 当前问题

现有渲染主要是背景、留白、图片圆角、单层边线和投影；没有标题栏、窗口框体，也没有框条、卡纸、内沿与材质层次。四套预设中两套偏背景，两套偏水印用途，视觉结构变化较少。

当前预设卡片用简化占位图表示样式，不能准确展示照片或截图套用后的真实效果。用户已经认可编辑器整合流程，本轮保留工作区布局，重点升级样式结构、默认搭配和预设预览。

## 3. 推荐的两条样式路线

### A. 截图展示：完整窗口外壳

1. **Mac 浅色窗口**：浅灰标题栏、红黄绿按钮、可选居中标题、细描边、上缘高光和分层投影。默认搭配低饱和雾绿背景。
2. **Mac 深色窗口**：深石墨标题栏、较弱的边缘高光和深色投影。背景使用石墨、深蓝等低对比色，适合代码和暗色软件截图。
3. **极简浏览器框**：独立的地址栏与可选标题，适合网页、产品页和教程配图。地址内容由用户填写，不从图片中猜测。

Mac 窗口框指包含三色按钮的窗口外壳。MacBook 电脑机身、iPhone 等设备样机属于后续独立方向。

窗口框在截图外侧扩展，不覆盖原有像素。对已经包含系统标题栏的截图，提供完整标题栏、紧凑三色按钮和无外壳选择；用户也可以使用现有裁剪去掉原窗口栏，避免重复套框。

### B. 照片展示：框条、衬纸与内沿

4. **黑框画廊**：窄黑框条、暖白卡纸、细内沿和内凹阴影；整体圆角接近零，呈现规整装裱感。
5. **浅木装裱**：四条有方向的木纹框条、45° 拼角、奶油色卡纸、薄的第二层衬边和克制的投影。后续可从同一结构扩展胡桃木。
6. **拍立得纸框**：纸张底色和微弱质感、上窄下宽留白、可选日期与署名；轻微旋转作为可选项，默认不遮挡或裁掉图片。

装裱层次由外到内为：背景 → 框条 → 卡纸 → 内沿/斜切口 → 图片。外投影体现整体厚度，内阴影体现图片嵌入；二者独立控制。默认不加玻璃反光，保证图片与截图文字清楚。

## 4. 预设与交互

- 预设分为「截图展示」「照片装裱」，保留用户当前认可的三页侧栏与底部工具栏。
- 首批六种风格以第 3 节为准。每套预设配好背景、框型、尺寸比例、投影和文字位置，而非只改背景颜色。
- 优先实现 Mac 浅色、Mac 深色、黑框画廊和浅木装裱四种；再补浏览器框和拍立得。
- 原「品牌署名」「资料标记」作为水印配置保留，不占主要相框风格入口。
- 相框页先选择框型，再显示对应参数：Mac 显示标题栏与三色按钮选项；画廊/木框显示框条、衬纸和内沿；纸框显示纸色、下边距和说明。高级材质参数折叠。
- 背景设置独立于外框，可搭配透明、纯色、渐变；后续再扩展图片背景、模糊原图和多点渐变。
- 预设缩略图使用真实合成路径绘制当前图片的小图，准确反映框体与留白；按内容和预设缓存，不在每次滑块更新时重建整个图库。
- 图片完整显示为默认行为，不为适应相框而拉伸或自动裁剪内容。图片圆角、窗口外圆角、框条厚度和卡纸宽度分别计算。

## 5. 实现建议

现有 `BeautifyFrame.kind` 同时承担背景与边框分类，继续追加样式会增加耦合。建议将可持久化参数分成背景、外框/装裱、构图三部分，保留现有水印列表和编辑历史接口。

- **背景**：透明、纯色、渐变及相应颜色参数。
- **外框/装裱**：框型、主题、窗口栏、标题、框条、卡纸、内沿及对应细节。
- **构图**：外围留白、对齐、最终画布比例与整体投影。

跨端模型先定义在 `src/api.ts`，再更新 Rust 校验与 schema 迁移。已有预设的纯色/渐变背景、圆角和阴影迁移为等效的背景卡片组合，保持旧预设外观与 ID 可用。

Mac、浏览器、画廊和纸框优先用 Canvas 几何绘制，任意分辨率均保持清楚；木框采用小尺寸可重复材质与独立角部/边部处理，纹理沿框条方向排列，不拉伸整张相框 PNG。最终效果仍由共用渲染器绘制，预览与导出保持一致。

实施时同步三语文案，并重点回归窗口栏增加后的标注坐标、成品适配、不同宽高比、四角拼接、透明输出、水印定位和旧预设迁移。
