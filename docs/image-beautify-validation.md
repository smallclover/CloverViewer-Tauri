## 整轮美化与对比验证

`node tools/check-beautify-round.cjs` 使用真实编辑器与 Chrome Canvas，通过以下交互：

- 同轮四套相框、文字水印及海报标题一次撤销/重做；文本框内 Ctrl+Z / Ctrl+Shift+Z 同样按整轮处理。
- 已完成的美化之后开始新轮，本次还原保留上一轮；空轮、净零变化和还原本次不新增记录，未修改/还原后可直接退出。
- 按住对比前后逐像素一致，松手到按钮外、Space 按住和窗口失焦均恢复最新结果；比较期间参数不回退。
- 水印拖动遇到失焦只恢复偏移，保留本轮标题及水印层；没有回退整轮。
- 标注 → 多套框试用 → 标注，严格按三步撤销/重做；保存自动形成新边界。
- 比较期间触发保存会停止比较，并导出实际当前成品的尺寸；取消路径选择后新调整保持独立的边界由控制器单元测试覆盖。
- 中文、英文、日文的侧栏按钮和已有海报、相框交互回归通过。

新增 11 项前端单元测试覆盖会话事务、净零修订、已有 redo 分支、交叉编辑顺序、保存取消边界和鼠标/键盘对比取消。截图在 `.unit-test-dist/beautify-round-*.png`。本轮仅涉及前端，未重跑原生 WebView2 脚本。
