# OCR 结果交互实现与验证

日期：2026-10-24。对应 [v1 交互设计](ocr-interaction-proposal.md)。

## 实现范围

- 系统与 Paddle 引擎返回输入图片像素坐标、识别行和原始文本。系统预处理缩放按实际宽高分别还原；Paddle 保留分片偏移后的四边形。旧纯文本命令和 MCP 仍使用同一次识别结果的文本投影。
- 截图 OCR 使用识别时的原始选区像素打开查看器，`finishScreenshot`、`open-image` 与主窗口一起传递结构化结果。过期截图会话不提交迟到的 OCR。
- 默认 340px 的分块侧栏，可拖到 300–440px；按段落/按行选择，分块/全文切换，保留按行选择和半选状态。
- 原图悬停、点击与 Ctrl 多选、拖框选择识别行；侧栏正文可原生拖选字符。点击侧栏正文强调原图，来源不在视区时平移到可见位置，保留当前缩放。
- 覆盖层复用图片的实际 CSS 变换，并使用 SVG 屏幕矩阵做框选；缩放、旋转和翻转同步。框线与编号保持屏幕尺寸。空格拖动或中键平移；也能切换浏览图片模式。
- 每段可编辑、取消或恢复原识别文字。编辑后的段落成为整块选择，全文和两种复制格式共同使用新文字，避免复制旧行。编辑结束恢复键盘焦点。
- 复制所选按稳定阅读顺序输出，支持整理段落/保留原换行；原生选中文字或编辑框内的 Ctrl+C 优先。复制失败保留内容与选择。
- Esc 按取消拖动/编辑、清空选择、关闭面板的顺序执行；失焦、捕获丢失、坐标变换和面板关闭清理拖动状态。
- 结果按文件大小/修改时间校验，会话缓存最多 12 项并按约 32 MiB 估值淘汰。旧纯文本结果作为单块显示，不编造坐标。
- 内容宽度不足 900px 时侧栏移到下方；短窗口允许面板滚动以保持操作可达。新增产品文案同步中英日三语。

## 自动验证

- `npm run check`：格式、lint、类型、前端单元测试与版本一致性。
- `npm run build`：生产前端构建。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib`：80 项通过，4 项依赖真实资产的测试默认忽略。
- 针对本次用户截图显式运行 `structured_input_sample`：系统引擎 37 行、Paddle 58 行，验证输入尺寸、坐标边界与结构化结果。该测试不以不同引擎输出相同文字为断言。
- 使用真实 debug 可执行文件的 `--ocr-worker` 入口传入该 PNG：Paddle 子进程成功输出 58 个唯一 ID 的行，所有四边形均在 1275×958 输入图片范围内。
- 完整生产前端加 Tauri 接口夹具：注入上述真实 Paddle 结果，点击原图末尾消息，仅该段被选中，复制内容不含文件路径；检查启动、桥接、图片加载和控制台运行错误。

`tools/check-ocr-interaction.cjs` 是可重复的浏览器交互检查。需要现有的 Playwright 与 Chrome；不向产品增加依赖。可通过 `CLOVER_PLAYWRIGHT_MODULE` 指定本机 Playwright 模块，然后运行：

```powershell
node tools/check-ocr-interaction.cjs
```

它检查点选、多选、框选部分行、阅读顺序、编辑后的复制、原生字符选择优先、失败保留选择、旋转翻转、取消、空格平移、视区外定位、中英日三语、1200/640/360px 宽度、360×425 的短窗口、旧文本与同路径版本失效。预览图写入被忽略的 `.unit-test-dist/`。

运行真实引擎检查时，设置 `CLOVER_OCR_TEST_IMAGE` 为样例 PNG 路径，再执行：

```powershell
cargo test --manifest-path src-tauri/Cargo.toml --lib structured_input_sample -- --ignored --nocapture
```

已安装的 Paddle 组件会一并测试；未安装时只运行系统引擎。可选 `CLOVER_OCR_TEST_OUTPUT` 将系统结构化结果写到指定测试产物文件。

## 桌面验证边界

本轮已在真实开发窗口触发 Alt+S、显示截图覆盖窗并退出。自动化在多屏截图窗口中使用的坐标与可见截图发生偏差，因此没有将这一轮操作记为完成原生 OCR 端到端验收。

尝试进一步检查 WebView 开发工具时，自动审批拒绝访问 `msedgewebview2`，提示进程未获授权；未绕过该限制。实际剪贴板、截图到查看器与所有 DPI/屏幕组合的完整桌面手工回归仍需补测，浏览器夹具不能替代这些项目。

## 已知范围

原图选择粒度是引擎返回的识别行/块；右侧正常文字可选择到字符。段落分组采用几何规则，复杂表格、竖排和复杂多栏的阅读顺序仍可能不准确，可切换按行选取。没有新增语义分析、表格还原或精确原图逐字坐标。
