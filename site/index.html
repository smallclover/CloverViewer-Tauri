免费开源的 Windows 图片查看器与长截图工具

CloverViewer 把图片浏览、多屏截图与标注、滚动长截图、Windows 原生 OCR 取字，以及一个面向 AI 的 MCP Server 装进同一个轻量应用。基于 Tauri 2（Rust 后端 + Vite/TypeScript 前端）重写，MIT 协议开源，无广告、无捆绑、无需注册。

功能一览

🖼️ 图片查看器

网格视图与单图视图随时切换；打开文件夹即加载全部图片，大目录使用虚拟滚动与缩略图 LRU 缓存，上千张图也不卡。滚轮缩放、拖拽平移、旋转翻转、←/→ 快速切换，并显示尺寸、 体积、修改时间与 EXIF（相机、ISO、光圈、快门、焦距、镜头）。

📸 截图与标注

跨屏拼接虚拟桌面截图，支持活动窗口吸附与区域框选；矩形、椭圆、箭头、画笔、马赛克、 文字六种标注，颜色与线宽随手切换，Ctrl+Z / Ctrl+Y 撤销重做，Enter 直接复制到剪贴板或保存到桌面。

🧵 滚动长截图

框选一块可滚动区域后自己滚动，程序逐帧按重叠像素配准，只把验证通过的新内容拼进长图， 并自动跳过吸顶标题栏、吸底工具栏与固定侧栏。聊天记录、网页全文、长列表、代码 diff 都能变成一张图。

🔍 OCR 文字识别

基于 Windows 原生 UWP OCR 引擎（Windows.Media.Ocr）识别中、英、日文字， 带灰度 + 2× 最近邻放大预处理，截图取字不需要把画面发给任何在线服务。

🤖 面向 AI 的 MCP Server

内置 Model Context Protocol 服务， Claude Desktop 等客户端可调用 list_monitors、take_screenshot、 get_screenshot、ocr_screenshot、delete_screenshot， 让 AI 直接看到报错窗口、设置页或终端输出。

⚙️ 系统集成

标题栏菜单（文件 / 编辑 / 帮助）与「分类 + 搜索」的设置页；全局热键（默认 Alt+S 截图、 Alt+Shift+S 长截图）、系统托盘常驻、开机自启、单实例运行、明暗主题跟随系统，以及与旧版 egui 版共用的配置文件。设置 → 缓存 可查看临时长截图的占用、设置保留期或立即清理。

滚动长截图是怎么做的

CloverViewer 的长截图默认由你控制滚动位置：程序只负责稳定取帧、配准、拼接和反馈。 每个被接受的帧都必须有足够的纹理证据和像素支持，未匹配、反向或重复的帧不会改写拼接基准； 结束采样同样要通过同一套门槛，所以末帧不会被重复追加。

  • 输出可追溯：长图中的每个像素都来自某一帧真实屏幕截图，而不是推算出来的。
  • 固定栏只保留一份：吸顶标题栏来自首帧，吸底工具栏来自末帧，滚动条与固定侧栏自动忽略。
  • 中途也能续接：出现未匹配帧只是跳过，继续滚动后仍能从最后一个可信位置接着拼接。
  • 失败可解释：不可滚动、选区太矮、动画干扰等原因分别给出提示，Esc 停止时已捕获部分保留。
  • 自动滚动是试验功能：默认关闭，开启后由程序探测目标应用接受的滚动方式（滚轮消息 / 模拟滚轮 / PageDown / 滚动条）。

下载与安装

  1. 到 Releases 下载 CloverViewer_x.y.z_x64-setup.exe（NSIS 安装器，per-user 安装，不需要管理员权限）。
  2. 也可以直接下载便携版 CloverViewer.exe，放在任意目录运行。
  3. 系统要求：Windows 10 / 11（含 WebView2 运行时）；从源码构建需要 Rust、Node.js ≥ 18 与 Tauri 2 工具链。
  4. 支持的图片格式：PNG · JPEG · GIF · BMP · WebP · TIFF。

应用内更新已支持签名校验：从 v0.1.5 起可在「设置 → 软件更新」中检查、下载并自动重启安装；自 v0.1.8 起检查完全由你手动触发，应用不会在后台自动联网。

常见问题

CloverViewer 是免费的吗？可以商用吗？

免费且开源，协议为 MIT：个人使用、公司内部使用和二次开发都可以，只需保留版权声明。

支持哪些 Windows 版本？

Windows 10 / 11，依赖系统自带的 WebView2 运行时。安装包是 NSIS 的 per-user 安装，不需要管理员权限；也可以直接使用便携版 CloverViewer.exe。

会把我浏览的图片或截图上传吗？

不会。图片浏览、截图、标注、长截图拼接和 OCR 全部在本机完成，应用没有账号体系，也不收集使用数据。唯一的联网行为是「检查更新」：只有你在「设置 → 软件更新」中点「检查更新」时，应用才会访问 GitHub Releases 获取版本信息，不会在后台自动联网。

长截图（滚动截图）支持所有应用吗？

不保证 100% 成功。默认是手动滚动优先：你按自己的节奏滚动，程序逐帧配准并只把验证通过的新内容追加进长图；自动注入滚动属于设置里的试验功能，默认关闭。目标应用有粘性标题栏、动态内容或大面积动画时成功率会下降，失败或中途停止时已捕获的部分会保留。

和其它截图工具有什么不同？

它把「图片查看器」和「截图标注」合在同一个免费开源应用里，并且内置 MCP Server 让 AI 客户端可以直接调用截图与 OCR。长截图走的是「真实帧 + 重叠像素配准」路线：输出中的每个像素都来自某一帧真实屏幕画面，而不是推算出来的。

和原版 CloverViewer（egui 版）是什么关系？

本页介绍的是 Tauri 2 重实现：Rust 后端 + Web 前端（Vite + TypeScript + Canvas），界面由 egui 原生控件换成自定义无边框窗口。两者配置文件互通，共用 %APPDATA%\CloverViewer\config.json。原 egui 版见 smallclover/CloverViewer。

怎么让 Claude Desktop 用上截图能力？

在 claude_desktop_config.json 中配置 CloverViewer.exe --mcp 即可， 详见 MCP 使用指南。 HTTP 模式需要显式提供 --token，只监听本机回环地址。

English overview

CloverViewer is a free, open-source Windows image viewer and screenshot tool built with Tauri 2 (Rust backend, Vite + TypeScript frontend). It browses folders in a virtualized grid or a single-image view with EXIF details, captures and annotates screenshots across multiple monitors, stitches scrolling screenshots from real captured frames, extracts text with the native Windows OCR engine (Chinese, English, Japanese), and ships a built-in MCP Server so AI clients such as Claude Desktop can list monitors, take screenshots and read on-screen text. Trilingual UI (简体中文 / English / 日本語), global hotkeys, tray support and signed in-app updates are included. Licensed under MIT.
