# 浮层分类与布局规范

应用内浮层采用紧凑横排风格。`src/styles/floating-ui.css` 是公共外壳与布局来源，
主窗口和截图窗口均导入它；颜色分别映射到主窗口与截图窗口的主题变量。
位置、可见性、任务状态及回调仍由各领域控制器管理。

## 按功能分类

| 类别 | 现有入口 | 布局规则 |
| --- | --- | --- |
| 轻提示 | 主窗口 `createToast`；普通/长截图的 `scroll-notice`；复制、保存、热键、缓存操作结果 | `floating-surface floating-notice`：小图标与文字横排，允许长文字换行，不预留独立按钮行。 |
| 异步状态 | 检查/下载/安装更新；桌宠加载；图片准备、OCR 等持续进度提示 | 左侧状态图标，中间标题/说明/可选进度，右侧关闭与倒计时。短任务可复用持续轻提示；有重试和详情的任务使用完整状态面板。 |
| 操作确认 | 未保存退出、覆盖原图；发现新版本与更新日志 | 同一外壳、图标/标题、可变内容、底部操作区。安全操作在左，主操作在右；图片编辑确认统一使用绿色提示图标和绿色主按钮，操作含义由明确文案表达。不自动关闭。 |
| 内容对话框 | 快捷键说明 | 标题/说明与右上关闭横排，主体按内容分组，底部关闭靠右。长内容只滚动主体，保留标题和操作区。 |
| 任务/工具面板 | 滚动截图开始/捕获/结果；主查看器与截图侧的局域网分享 | 共用标题、间距、按钮与操作区。保留各自的预览、数据、二维码、到期状态；取消/停止在前，开始/结束/复制等主操作在后。复杂结果允许分栏及换行。 |

## 共用类

- `floating-surface`：边框、背景、阴影、圆角、正文和长文字换行。
- `floating-notice`：轻提示的横排、内边距和小圆角。
- `floating-header` / `floating-heading` / `floating-title` / `floating-hint`：标题行、文字伸缩和字号。
- `floating-body`：可伸缩主体的内边距。
- `floating-actions` / `floating-footer`：靠右排列的操作区，窄窗口自动换行。
- `floating-action`，可附加 `primary` / `danger`：统一按钮尺寸、状态和焦点轮廓。
- `floating-close` / `floating-symbol`：关闭按钮和状态图标，警告图标附加 `warning`。
- `floating-share-*`：主窗口与截图分享共用的说明、链接和状态信息格式。

新入口优先组合这些类。需要不同的内容宽度和任务主体时，在领域样式中处理，
不要重新定义一套圆角、标题、按钮和操作区。

## 行为与边界

- 当前“已是最新版本”提示保留 5 秒自动关闭及倒计时；手动关闭、再次检查会清理旧计时器。
- 更新失败保留错误详情与重试，任务处理中保持状态可见。普通轻提示沿用原来的显示时长。
- 模态确认保留焦点恢复、Esc 和安全默认选项；快捷键弹窗保留键盘隔离及窄窗口单栏。
- 截图面板保留选区外定位、鼠标穿透与捕获时临时隐藏；布局变化仍通过原有测量重新落位。
- 主查看器的分享保留侧栏，截图分享保留浮层；布局一致不改变业务状态与生命周期。
- 主查看器分享的所有状态使用同一整体居中容器：有效分享的文件名、说明、二维码、链接、到期信息及操作沿同一中轴组成完整区域；失效、生成中和失败状态沿用相同的居中位置。生成中禁用按钮，失效后提供“重新分享”，失败后提供“重试”。短窗口允许内容滚动，保证操作可访问。
- 设置和关于为整页；属性/OCR 侧栏、参数弹层、菜单与下拉框服从各自的交互类型。
  Windows 原生打开/保存选择器由系统管理。
- 检查浅色/深色、中文/英文/日文、窄窗口、长错误和减少动态效果设置。
