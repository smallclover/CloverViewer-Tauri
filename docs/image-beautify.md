# 轻量图片美化

普通截图选区完成后，点击「图片美化」进入主窗口的图片编辑器。普通图片先进入编辑，再点击同名按钮。美化用于快速整理截图和图片的分享外观；右侧仅保留「样式 / 水印」两页，不提供海报排版。

## 样式

默认展示截图样式：清爽分享、Mac 浅色窗口、Mac 深色窗口、极简浏览器。照片分类提供黑框画廊、浅木装裱和拍立得；也可切换到全部或个人预设。缩略图使用当前图片和实际渲染器生成。

选择样式后，同页只需调整：

- 背景：透明、白色、深灰、薄荷绿、雾蓝、粉紫，或自定义纯色。
- 留白：小、中、大，统一作用于四边，按图片短边等比例适配。

圆角、阴影、标题栏高度、框条、卡纸和内沿等细节由预设决定，没有高级参数面板。原图内容不因套框自动拉伸或裁剪。阴影所需空间计入成品尺寸。

## 水印

可添加文字和 PNG Logo，每类新建一个；再次点击添加会选中已有同类水印。文字支持多行、颜色，以及使用本次会话固定时间的 {date} / {time} 变量。

调整大小、不透明度和九宫格位置，也可直接在图片上拖动。选择九宫格位置时，水印回到图片内容区的单个定位，重置偏移与旋转。常规操作不提供平铺、旋转、描边、字体、目标区域和图层排序等参数。

Logo 导入后复制到应用素材目录，不依赖原始文件。缺少素材时需要重新导入、禁用或删除水印；导出不会静默丢失启用的 Logo。

## 编辑、撤销与保存

美化、标注共用画布、缩放和底部保存选项，侧栏底部显示最终输出尺寸。输出比例作用于整个成品，PNG/WebP 保留透明区域，JPEG 的透明区域铺白。

一轮美化内的样式切换、背景、留白和水印修改实时预览，整轮只占一步撤销。切换页签、失焦、松开滑块或水印拖动不会结束本轮。

- 「完成美化」、收起侧栏、侧栏内 Esc 或再次点击美化按钮，保留效果并结束本轮。
- 标注、裁剪、旋转、重置和保存会结束本轮，再执行原操作。侧栏继续打开时，后续美化进入新一轮。
- 全局撤销/重做和侧栏内 Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 使用相同的整轮历史。
- 「还原本次」只恢复本轮开始前的美化；「按住对比调整前」临时显示原效果，释放或失焦后恢复当前效果。
- 没有修改、还原本次或参数回到完全相同的状态，不新增历史或未保存状态。
- 水印拖动取消或失焦只恢复本次移动，不撤销本轮其他调整。

截图跳转携带未叠加美化的选区图片、参数和截图时间，避免重复套用预设；已有截图标注在跳转时合成为基础图片。直接复制、保存和分享使用当前截图预设，OCR 始终读取原始截图。裁剪时暂时显示原图，完成后恢复成品预览。退出未保存编辑仍会询问。

## 个人预设与兼容

「保存与管理个人预设」内可以输入名称、保存新预设、更新/改名和删除个人预设。模板保存的是参数与素材引用，按图片短边等比例适配。

「预设与自动应用设置」可选新截图的默认样式，自动应用默认关闭。普通图片编辑从关闭美化开始，截图跳转使用本次截图参数。

预设保存于配置目录的 beautify.json，Logo 位于 beautify-assets/。写入采用原子替换与修订号冲突检查。损坏或不兼容的数据不会被静默覆盖。

schema 1/2 读取时升级至 schema 3，旧预设 ID、相框、背景、水印与修订号保留。旧相框细节及水印平铺等参数继续用于兼容渲染，但不提供新建这些效果的常规控件。海报排版代码已删除：旧海报预设使用其相框配置，读取不重写源文件，下次保存时去除已退役的海报字段。

## 边界与验证

- 内容和成品均不超过 2400 万像素，单边不超过 32767 px；超限会提示。
- Logo 最多 8 MB、1600 万像素，实际格式必须为 PNG。
- 导出为扁平图片，不提供可恢复图层的工程文件、模板包导入导出或批量处理。
- 滚动截图需先在查看器中打开后编辑，并受上述尺寸限制。

运行 npm run check、cargo test --manifest-path src-tauri/Cargo.toml --lib 和 npm run build 验证静态检查、单元测试与构建。

可设置 CLOVER_PLAYWRIGHT_MODULE 指向 Playwright，再运行 node tools/check-beautify.cjs 验证轻量面板、配色、留白、水印、预设、导出、三语和窄屏。node tools/check-beautify-round.cjs 验证整轮历史、对比、拖动取消和保存边界；node tools/check-frame-styles.cjs 检查实际 Canvas、比例换算与原图像素。原生回归入口为 tools/check-beautify-native.cjs。验证产物保存在被忽略的 .unit-test-dist/。
